# VEX — Personal Rule-Based AI Chatbot

## Project Overview

VEX is a lightweight, rule-based personal AI chatbot developed in Python. The project demonstrates the implementation of a conversational system using predefined rules, conditional logic, and Python's built-in libraries.

The primary objective of VEX is to provide a simple and efficient command-line chatbot while demonstrating fundamental concepts of Python programming, including functions, conditional statements, loops, string processing, random selection, and date/time handling.

## Key Features

- Rule-based conversational responses
- Greeting and general conversation handling
- Programming and technology-related responses
- Python, AI, HTML, CSS, JavaScript, PHP, API, server, and database information
- Current date and time functionality
- Random programming jokes
- Built-in help and command system
- Graceful shutdown using exit commands
- Lightweight implementation with no external dependencies

## Technologies Used

- Python 3
- `random` module
- `datetime` module
- Conditional statements
- Functions
- Loops
- String processing
